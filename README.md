# Student Management System

A responsive Student Management System built with **React, Vite and Tailwind CSS**.

## Features
- Add student records
- Search/filter students
- Delete student records
- Course selection
- Responsive dashboard UI
- Clean component-based React implementation

## Tech Stack
- React
- Vite
- Tailwind CSS
- JavaScript
